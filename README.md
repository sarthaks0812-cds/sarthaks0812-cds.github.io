# Sarthak Sahoo — single-page portfolio

A GitHub Pages website built with the Minima Jekyll theme and a custom responsive portfolio layout. The home page contains About Me, Projects, Work Experience, Publications and My Notes. The CV navigation link opens the included PDF. Markdown notes have their own reading pages; the portfolio itself remains one page.

## Publish on GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your GitHub username). If you already have one, back it up before replacing files.
2. Extract this ZIP and upload the CONTENTS of `sarthak-portfolio` to the repository root. `index.html`, `_config.yml` and `_layouts` must be at the top level, not inside an extra folder. Include files and folders starting with underscores.
3. In `_config.yml`, set `url: "https://YOUR-USERNAME.github.io"`. Leave `baseurl: ""` for this repository name.
4. Open repository Settings → Pages. Under Build and deployment choose Deploy from a branch, `main`, and `/ (root)`, then Save.
5. Wait for the Pages build to finish. Your site will be at `https://YOUR-USERNAME.github.io/`.

For a project repository named `portfolio`, use `baseurl: "/portfolio"` instead. All internal URLs use Jekyll's `relative_url` filter, so both arrangements work. Do not add `.nojekyll`.

Official setup: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
Theme: https://github.com/jekyll/minima (MIT license; the theme is installed by GitHub Pages, not copied into this package).

## Update the content

- Edit `index.html` for your biography, project descriptions, experience, publications and skills.
- Replace `assets/pdf/Sarthak-Sahoo-CV.pdf` to update your CV; keep its filename.
- Edit `assets/css/portfolio.css` for colors, spacing and fonts. `assets/main.css` is generated by the Minima theme when Jekyll builds.
- Your supplied CV is included unmodified and includes the contact details you provided. The homepage uses email and LinkedIn.

## Add Markdown notes

1. Copy `_notes/template.md` to `_notes/linear-systems.md`.
2. Change its front matter to:

```yaml
---
title: Linear systems and state-space models
topic: Controls
draft: false
---
```

3. Write your note below the front matter and commit. It appears in My Notes automatically, with a reading page at `/notes/linear-systems/`.
4. Use Markdown headings, lists, code blocks and images. LaTeX math rendering is not enabled by default; equations can be included in PDFs, or you can add a math-rendering library later.

The supplied draft template is intentionally hidden from the home-page listing.

## Add PDF notes

1. Upload a PDF to `notes/files/linear-systems.pdf`.
2. Replace the empty `[]` in `_data/note_files.yml` with:

```yaml
- title: Linear systems and state-space models
  topic: Controls
  file: /notes/files/linear-systems.pdf
```

Add subsequent entries using the same format, with no additional `[]` line. Uploaded PDFs appear only when listed in this index.

## Optional local preview

Install Ruby and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve
```

Open http://localhost:4000. GitHub Pages does the build automatically; local Ruby is not required to publish.
